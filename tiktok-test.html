TikTok purchase test

Sends one test "CompletePayment" (purchase) event to TikTok through the same server connection real purchases use. It is marked as a test, so it will not count in your ad reporting.

  1. In TikTok Events Manager open the pixel, then Test events, and copy the test event code.
  2. Paste it below and press the button.
  3. The event should appear in the Test events tab within a minute.
